# Triage labels

The skills refer to five triage roles. This file maps each role to the label string this repo's issue tracker uses.

| Role              | Label in our tracker | Meaning                                       |
| ----------------- | -------------------- | --------------------------------------------- |
| `needs-triage`    | `needs-triage`       | A maintainer needs to evaluate the issue      |
| `needs-info`      | `needs-info`         | Waiting for the reporter to add information   |
| `ready-for-agent` | `ready-for-agent`    | Fully specified, so an agent can do it alone  |
| `ready-for-human` | `ready-for-human`    | Needs a human to implement it                 |
| `wontfix`         | `wontfix`            | Will not be done                              |

When a skill names a role, for example "apply the `ready-for-agent` label", use that role's label string from this table.

Change the "Label in our tracker" column to the labels you actually use.
